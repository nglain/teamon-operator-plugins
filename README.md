# TeamON — каталог плагинов

Наш Git-каталог для Codex. Здесь только готовые пакеты и их зависимости:
без паролей, личных входов, настроек и переписок компаний.

## Начать с экрана установки

Нужны Codex с plugins/MCP Apps, Git и Node `>=24.14.1 <25` в PATH приложения.
Основной проверяемый путь — macOS/Linux. Windows пока не принят.

```sh
codex plugin marketplace add https://github.com/nglain/teamon-operator-plugins.git
codex plugin add teamon-installer@teamon-operator
```

Если наш каталог уже подключён на main, вместо первой команды:

```sh
codex plugin marketplace upgrade teamon-operator
```

Не подменяйте каталог с другим источником или закреплённым ref автоматически.
GitHub-аккаунт для чтения этого публичного каталога не требуется.

1. В новом чате выберите **@TeamON Installer** и попросите «Покажи установку».
2. Нажмите **Установить Operator** в бело-золотой карточке.
3. После проверенных 100% нажмите **Начать** и подтвердите отправку, если Codex спросит.
4. Продолжите в том же чате: **@TeamON Operator** → браузерный вход → выбранная
   компания → проверка доступа → короткий гайд. Если tools не появились,
   выберите Operator через `@`; не переустанавливайте здоровый пакет.

Bootstrap Installer происходит до экрана. Installer показывает реальные этапы;
плавность между проверками — оценка, таймер — измеренное время. 100% не означает
вход в компанию. Рабочее место самого Operator — обычный чат, не отдельный пульт.
Пароли вводятся только на защищённой странице входа. Доступы назначает администратор.

Уже есть Installer из `personal`? Для перехода согласуйте один источник и отключите
старый helper, чтобы не подключать два одинаковых MCP. Личные настройки не удаляйте.

## Что поставляется

- **TeamON Installer 0.1.0** — отдельный live MCP App для установки и перехода к входу.
- **TeamON Operator 0.2.11** — стабильный рабочий MCP; его пакет этой публикацией не изменён.

Инвентарь Installer: `plugins/teamon-installer/distribution.json`.
Исходный инвентарь Operator: `distribution.json`; его исходный хеш каталога
сохранён как исторический. Добавление второго плагина не меняет bytes Operator.
Релизные пакеты не содержат private Git history. Source Git и публикация пакета
— разные операции; после обновления каталога установленный runtime проверяется отдельно.

## Чего эта публикация не доказывает

CLI smoke подтверждает discovery/start/readiness, не фактическую видимость карточки
в любом Codex. Авторизация, назначения и чтение компании проверяются на устройстве
оператора. Ни установка, ни onboarding не отправляют сообщения сотрудникам и не
меняют агентов для демонстрации. Подробности: [Installer](plugins/teamon-installer/README.md).
